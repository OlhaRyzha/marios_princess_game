# Changelog

All notable changes to this project are documented here.

## Unreleased

### Added

- Ukrainian and English interface text with an in-game language toggle.
- Automatic progress persistence for desktop and browser builds.
- Static type checking, English docstring validation, and web archive validation.
- Asset size budgets, code coverage enforcement, and release documentation.
- Mute and fullscreen keyboard controls.

### Changed

- Split collectible, map visual, objective card, and camera behavior into focused modules.
- Reorganized tests into fixtures, factories, unit tests, and integration tests.
- Simplified local setup around `uv`, Make, pre-commit, Ruff, Black, and Pyright.

### Fixed

- Boss projectiles can be fired reliably with `J` during boss fights.
